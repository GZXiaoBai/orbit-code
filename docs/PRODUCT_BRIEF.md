# Product Brief

## Goal

Build a cross-platform desktop coding agent with clear conversational workflow, richer model/provider choice, executable Coding Plan imports, and a distinct Agent Workbench visual identity.

## Target User

Individual developers who want a local-first coding agent manager with clear review boundaries.

## Product Principles

- Conversation first, dashboard second.
- Local execution must be explicit and reviewable.
- Plans become structured work, not just context blobs.
- Multi-model support should be useful, not decorative.
- The default UI should feel calm, native, and low-friction without visually cloning existing agent products.
- Black and white themes should be first-class and share the same layout density.

## Core Workflows

1. Open a project and start or resume a thread.
2. Import a Markdown/YAML Coding Plan.
3. Let the agent read files, propose tasks, and prepare changes.
4. Review artifacts, command output, and file changes in-thread.
5. Approve, deny, or revise local tool actions.

## Out of Scope for the Next Phase

- Team collaboration.
- Cloud execution.
- Marketplace/plugin economy.
- Full IDE replacement.
- Enterprise SSO and audit exports.
